# ATLAS Access Point — Product Architecture

## Role

Dedicated wired-backhaul Wi-Fi 7 access point.

## Core requirements

- PoE-capable design for appropriate SKUs;
- tri-band Wi-Fi 7;
- multiple Ethernet speeds depending on model;
- ceiling/wall mounting;
- thermal design suitable for always-on operation;
- centralized management;
- local fallback operation.

## Hardware direction

Use an RF-first board layout, dedicated antenna architecture and low-noise power design. The final radio and Ethernet silicon must be selected together.
