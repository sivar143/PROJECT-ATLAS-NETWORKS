# ATLAS Mesh Node — Product Architecture

## Role

Wireless expansion node for ATLAS routers.

## Architecture

- Wi-Fi 7 tri-band or dual-band variant depending on SKU;
- dedicated wired backhaul where available;
- optional wireless backhaul;
- multiple spatial streams;
- secure pairing to controller/router;
- roaming optimization;
- local diagnostics.

## Key design rule

The mesh node must remain useful as a normal standards-compliant access point where feasible and must not require proprietary cloud connectivity for basic local networking.
