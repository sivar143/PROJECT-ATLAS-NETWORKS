# ATLAS Security Gateway — Product Architecture

## Role

Security and routing appliance for users who want dedicated firewall/gateway hardware.

## Core capabilities

- multi-WAN
- high-speed NAT
- stateful firewall
- IPv6 firewall
- VPN
- VLAN routing
- IDS/IPS where compute permits
- policy-based routing
- traffic analytics
- secure updates
- local recovery

## Product distinction

Unlike the X1, the gateway prioritizes wired throughput, security inspection, WAN resilience and serviceability over integrated Wi-Fi.
