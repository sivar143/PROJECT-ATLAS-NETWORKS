# Project ATLAS Networks

Project ATLAS is a premium networking product family. The current engineering baseline is ATLAS X1, a premium tri-band Wi-Fi 7 home/prosumer router.

## Engineering status

The repository now contains the product definition, PDS, and the next engineering-design layer required to move toward component selection, schematic capture, mechanical CAD, PCB design, prototype manufacturing, firmware bring-up, and certification.

IMPORTANT: these documents are an engineering architecture baseline, not fabrication-release documents. Exact ICs, RF front-end parts, power rails, connector ratings, PCB dimensions, impedance rules, thermal dimensions, and regulatory parameters must be frozen after component selection and simulation.
